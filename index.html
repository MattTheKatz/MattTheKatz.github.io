HitchPilot

Role

Company
Toolwright LLC
Timeline

Status
Live, in pilot

Online booking and operations for small trailer-rental yards. A renter books a trailer, signs the rental agreement, and pays from their phone in a few minutes.

The yard owner gets a dashboard, a calendar, and automated text and email reminders, and the deposit is held on the renter's card until a clean return.

I founded the company and built the platform from the first commit. It went from an empty repository to a live production site taking real card payments in under three weeks, and it is now in pilot with a trailer-rental yard in Lafayette, Louisiana.

Visit the live site Try the demo yard

What I built

  1. 01

    Payments that cannot double-charge

    Stripe Connect handles checkout, deposit holds, refunds, and date changes. Every payment instruction carries an idempotency key, every webhook event is reconciled, and a claim-first lock means two clicks at the same moment can only produce one charge.

  2. 02

    Messaging that respects people

    Confirmations, pickup instructions, return reminders, and late notices are scheduled automatically over SMS with an email fallback. A renter never gets the same message twice, late notices are capped, and an opt-out always wins.

  3. 03

    Agreements with a paper trail

    Renters sign the rental agreement on their phone before a booking is confirmed. The terms are snapshotted and hashed at signing, the signed PDF is emailed to the renter, and license and condition photos live in private storage.

  4. 04

    A safety net on every change

    Unit tests cover the pricing and fee math. Integration tests run against a real database. Browser tests book a trailer as a renter and work the dashboard as an owner. After each deploy, a check confirms the public pages still answer.

  5. 05

    Security as a foundation

    A strict Content Security Policy, secure session cookies, server-side input validation, invite-only staff accounts, rate limiting on sign-up and login, audit logging, and automated code, secret, and dependency scanning.

  6. 06

    A text assistant with guardrails

    Renters can text questions and get answers from an LLM-powered assistant. It is rate-limited, its replies are validated before they send, and it is hardened against prompt injection so it can never reveal a lockbox code.

A small function I'm proud of

Pricing looks simple until a customer extends a rental and the total goes down.

Yards offer a daily rate and a cheaper weekly rate. The obvious math, full weeks plus leftover days, has a flaw: six days at the daily rate can cost more than a full week. That means extending a rental could lower the price and trigger a refund.

This function takes the lowest of three prices, which guarantees the total never decreases as days are added. The test checks that property across thirty days instead of trusting a few hand-picked examples.

From HitchPilot's pricing library. It has no imports on purpose, so the server and the browser preview share one source of truth.

pricing.ts/**
 * Rental charge for a number of days. With a weekly rate
 * set, rentals are billed as full weeks plus leftover days,
 * but never more than rounding up to the next full week,
 * and never more than plain daily pricing. This keeps the
 * price non-decreasing in days, so extending a rental can
 * never produce a refund.
 */
export function quoteForDays(
  days: number,
  dailyRateCents: number,
  weeklyRateCents?: number | null,
): number {
  const plain = days * dailyRateCents;
  if (!weeklyRateCents) return plain;
  const weeks = Math.floor(days / 7);
  const rem = days % 7;
  const mixed = weeks * weeklyRateCents + rem * dailyRateCents;
  const roundedUp =
    (weeks + (rem > 0 ? 1 : 0)) * weeklyRateCents;
  return Math.min(plain, mixed, roundedUp);
}
pricing.test.ts// An extension must never lower the price.
it("is non-decreasing in days", () => {
  let last = 0;
  for (let d = 1; d <= 30; d++) {
    const q = quoteForDays(d, 12000, 70000);
    expect(q).toBeGreaterThanOrEqual(last);
    last = q;
  }
});
